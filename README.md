# ヨリスグリノート BEAUTY EDIT

スキンケア・メイク・ヘアケア・ネイルなど18テーマを扱う美容専門サイト。

## 公開設定
GitHub > Settings > Pages > Build and deployment > Deploy from a branch > main / (root)。

## 独自ドメイン
正式公開する際は `beauty.yorisuguri-note.com` のCNAMEを `a66173800-stack.github.io` に設定し、GitHub Pages側でカスタムドメインを設定する。DNSとGitHub Pagesの接続が完成するまでは旧美容サイトを削除しない。

## サイト構成
トップページ、18記事、ネイルサロン特集、CSS、サイトマップ、robots.txt。元の総合サイトとは別リポジトリで管理する。
